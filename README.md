# laughingstonks dump
Dumps all laughingstonks data to a single HTML file

## Installation
Install laughingstonks into KoLmafia by using this command in the gCLI:
```
git checkout VeeArrKoL/laughingstonks dump
```

This branch uses an entirely separate set of scripts and does not interfere with normal laughingstonks function.

## Usage

Browse to `http://<server>:<port>/laughingstonks_dump.js?relay=true` in your browser. The value of `<server>:<port>` will depend on the configuration of your mafia instance, but will likely look like `127.0.0.1:60080`.
